Violet Blue I

A low-level, binary stream-based virtual multimedia terminal architecture.

Main Page > Software Development Kit (SDK)
Download the Violet Blue I SDK for Windows. The SDK includes the official Violet Blue I host runtime environment, binary protocol documentation, C header files (`bluei.h`), and sample applications to help you get started with low-level stream programming.
Violet Blue I guest applications communicate with the host interface entirely through standard input and output streams using binary instruction packets (`CMD0`–`CMD5`). No external multimedia libraries, graphics engines, or complex linker setups are required.
