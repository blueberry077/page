PowerRenamer v1.0

Fast and easy batch file renaming for Windows.

PowerRenamer is a standalone Windows utility designed to rename large collections of files instantly using simple pattern tokens. Built using native code, it starts up instantly, uses minimal memory, and requires no installer or extra runtime dependencies.

Key Features

  • Token-based Renaming: Use pattern tokens to rename your files (such as: $index$, $index[n]$, $filename$, $ext$).
  • Instant Live Preview: See your renamed list update in real time as you type pattern tokens.
  • Automatic Collision Prevention: Smart internal indexing ensures duplicate filenames are automatically incremented safely without overwriting data.
  • Flexible Batch Ordering: Easily reorder files, remove individual or non-contiguous selections before renaming.
  • Zero Footprint: No setup wizards, no registry bloat, and no telemetry. Just unpack and run.
  • Native Speed: Compiled down to native machine code for maximum execution speed across thousands of files.

Quick Start Guide

  1. Extract PowerRenamer.exe to any directory or USB drive.
  2. Drag and drop files directly into the list view.
  3. Enter your custom pattern in the pattern input box (e.g., $name$_$index$.$ext$).
  4. Verify the result in the New Name column and click Apply.
  5. Click Run to start renaming the files.
