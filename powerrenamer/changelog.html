Version 1.0.1.3

Released: August 28th, 2026
  • Safety & Validation: Added validation before pattern application to block illegal Windows characters (\ / : * ? " < > |) and reserved system names (CON, PRN, AUX, etc.).
  • Performance & Safety: Implemented O(1) hash-set path verification to instantly prevent duplicate file entries during drag-and-drop and file addition operations.
  • Interface: Changed main window title for consistency.

Version 1.0.0.2

Released: August 26th, 2026
  • Core Engine: Introduced dynamic pattern token parsing for inline string formatting ($filename$, $index[n]$, $ext$).
  • Interface: Added real-time token preview column showing immediate rename results before executing.
  • Safety: Implemented automatic collision indexing to increment duplicate target filenames safely.
